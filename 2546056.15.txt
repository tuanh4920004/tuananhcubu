*  *args : Nhận bao nhiêu đối số cũng được.Python sẽ tự gom các giá trị đó thành tuple.

*     | Thành phần      | Ý nghĩa               |
| --------------- | --------------------- |
| `*args`         | Nhận nhiều đối số     |
| `args`          | Tuple chứa các đối số |
| `for i in args` | Duyệt từng giá trị    |
| `a += i`        | Cộng dồn              |
| `return a`      | Trả tổng              |

Cho phép hàm nhận linh hoạt nhiều giá trị khác nhau mà không cần biết trước số lượng.

def varfunc(* args) : 
    print(args)

def Sum(* args) : 
    a = 0
    for i in args : 
        a += i
    return a
#-------------------------------------------------------
print("하나의 값으로 호출")
varfunc(10)

print("여러 개의 값으로 호출")
varfunc(10,20,30)

print(Sum(10,20,30))



#===============================================
* Hàm Sum sẽ có tác dụng tự viết hàm cộng các số bằng vòng lặp 

* return sum(*s) : có nhiệm vụ lấy các phần tử bên trong ra riêng lẻ 

def varfunc(* args) : 
    print(args)

def Sum(* args) : 
    a = 0
    for i in args : a += i
    return a


def SUM(* args) :
    s = (args)
    return sum(*s)
#-------------------------------------------------------
print("하나의 값으로 호출")
varfunc(10)

print("여러 개의 값으로 호출")
varfunc(10,20,30)
print(Sum(10,20,30))

AA = [x for x in range(1,11)]
print(SUM(AA))

## Chương trình tính lương tuần

* Tạo hàm tên: `weekPay(rate, hour)`
* Điều kiện: nếu làm quá 30 giờ thì trả lương với mức 1.5 lần tiền công theo giờ.
* Sử dụng keyword argument và default value, đặt mặc định:

  * lương giờ = 1
  * thời gian làm = 1 giờ
* Nhập:

  * lương theo giờ
  * thời gian làm việc
* Xuất:

  > “Số tiền được trả là xxxxx won.”


def weekPay(rate = 10320,hour = 1) :
    if hour >= 30 : r = 1.5
    return (rate * hour)

#------------------------------------------------------------------------
rate = int(input("시급 >> "))
hour = int(input("근무 시간 >> "))
print("주급은 %0f원입니다."%weekPay(rate,hour))

def ADD(a,b) : return a + b
def SUB(a,b) : return a - b
def MUL(a,b) : return a * b
def DIV(a,b) : return a / b
def get_input() : 
    a = int(input("1 >> "))
    b = int(input("2 >> "))
    return a,b
